控制台（本页面）怎么读到这些数据

上面 7 个阶段是「鱼」在后台跑；控制台是另一条只读的旁路，不参与处理，也不发任何 B 站请求。

⑧
入口浏览器 → 本地控制台
GET http://127.0.0.1:8787/?token=… → token 只在启动时打印一次写进 URL，之后靠 Cookie 记住
三道闸 → 只监听 127.0.0.1 · Host / Origin 校验防 DNS rebinding · x-token
web/server.mjs
⑨
只读四个数据源，全是本地文件
配置 → config.json唯一一处可写
历史 → handled.jsonl · rejected.jsonl · alerts/
详情 → runs/<runId>/run.json · summary.md · prompt.txt · transcript.txt
GET /api/configGET /api/historyGET /api/run?id=POST /api/config
⑩
界面四个 Tab，各管一件事
配置 → 表单 分组可折叠 / JSON 源码，两栏互相同步
历史 → 已处理 / 已拒绝 / 静默三个分段 · 形态 + 素材源两个筛选，可叠加，纯前端过滤
召唤指令 → 说明表 + 可编辑词表写回 config.json 的 routing.keywords
架构图 → 就是这一页纯 HTML/CSS，不引外部资源
web/index.html
